puppy 0.2.1 lets you resize the dashboard's panes, and remembers the size you choose.

## What's new

- **Resizable panes.** Drag the border between Downloads and Details with the mouse, or press `<` / `>` to move it. This works side by side (wide terminals) and stacked (narrow ones). Double-click the border to put it back to the default. Each pane keeps a minimum size, so neither can be squeezed away.
- **Remembered between runs.** The size is saved as a share of the screen, so it scales when the terminal is resized. The side-by-side and stacked layouts each keep their own. A new dashboard opens where the last one left it. The file is `tui.toml` in puppy's data directory; it is written by the dashboard, and settings stay in `config.toml`.

## Upgrading

Nothing to do: 0.2.0 installs update to 0.2.1 by themselves, and your queue, settings and downloads carry over. Only the dashboard changed, so a 0.2.0 daemon that is still running works with it.

## Install

The quickest way:

```sh
curl -fsSL https://raw.githubusercontent.com/lavavrik/puppy/main/scripts/install.sh | sh    # Linux, macOS
```

```powershell
irm https://raw.githubusercontent.com/lavavrik/puppy/main/scripts/install.ps1 | iex          # Windows
```

Or pick the archive for your platform below, unpack it and put `puppy` on your `PATH`. Each archive also holds the browser extension (`extension/`), service files (`packaging/`), shell completions (`completions/`) and man pages (`man/man1/`). Step-by-step instructions are in the [README](https://github.com/lavavrik/puppy#install). Checksums are in `SHA256SUMS`.

| Platform | Archive |
|---|---|
| Linux x86_64 | `puppy-0.2.1-x86_64-unknown-linux-gnu.tar.gz` |
| Linux x86_64, static | `puppy-0.2.1-x86_64-unknown-linux-musl.tar.gz` |
| Linux ARM64 | `puppy-0.2.1-aarch64-unknown-linux-gnu.tar.gz` |
| Linux ARM64, static | `puppy-0.2.1-aarch64-unknown-linux-musl.tar.gz` |
| macOS Apple silicon | `puppy-0.2.1-aarch64-apple-darwin.tar.gz` |
| macOS Intel | `puppy-0.2.1-x86_64-apple-darwin.tar.gz` |
| Windows x86_64 | `puppy-0.2.1-x86_64-pc-windows-msvc.zip` |
| Windows ARM64 | `puppy-0.2.1-aarch64-pc-windows-msvc.zip` |

The `-gnu` builds need glibc 2.35 or newer; the static `-musl` builds need nothing, but resolve host names from `/etc/hosts` and DNS only (no mDNS `.local` names). The macOS and Windows binaries are not signed: see the README for the one-time Gatekeeper / SmartScreen step.

## Status

Early development. puppy is used and tested day to day on Linux, and this release is published only after the full test suite passed on every platform. On macOS and Windows, mouse dragging depends on the terminal reporting drags; the `<` / `>` keys work everywhere. Bug reports are very welcome.
