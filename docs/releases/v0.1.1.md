The first public release of puppy: a terminal download manager for HTTP(S) and BitTorrent, with a background daemon, a full-screen dashboard and a browser extension.

## What's in it

- **HTTP(S):** segmented multi-connection downloads with safe resume (a changed remote file is never silently continued), retries with backoff, per-download and global speed limits, proxies.
- **BitTorrent:** magnet links and `.torrent` files, file selection, seeding limits, peers and a piece map.
- **Daemon:** owns the queue and keeps downloading with no window open; state survives restarts. Can run as a login service (systemd, launchd, Task Scheduler).
- **Dashboard:** `puppy` opens a full-screen terminal UI to add, pause, reorder, limit and delete downloads.
- **Command line:** `puppy add`, `ls`, `info`, `wait`, `select`, … with `--json` output for scripts.
- **Updates itself:** once a day the daemon looks for a new release. When nothing is downloading and no window is open (seeding is fine), it installs the update and restarts into it; downloads resume where they were. The dashboard shows a banner when an update is out (Shift-U installs it right away), and `puppy update` does the same from the command line. Turn it off with `[update] check = false` or `auto_install = false`.
- **Desktop notifications** when downloads finish or fail.
- **Browser extension** (Chrome, Chromium, Brave, Edge, Vivaldi) that hands the browser's downloads to puppy, cookies included.

## Install

The quickest way:

```sh
curl -fsSL https://raw.githubusercontent.com/lavavrik/puppy/main/scripts/install.sh | sh    # Linux, macOS
```

```powershell
irm https://raw.githubusercontent.com/lavavrik/puppy/main/scripts/install.ps1 | iex          # Windows
```

Or pick the archive for your platform below, unpack it and put `puppy` on your `PATH`. Each archive also holds the browser extension (`extension/`) and service files (`packaging/`). Step-by-step instructions are in the [README](https://github.com/lavavrik/puppy#install). Checksums are in `SHA256SUMS`.

| Platform | Archive |
|---|---|
| Linux x86_64 | `puppy-0.1.1-x86_64-unknown-linux-gnu.tar.gz` |
| Linux ARM64 | `puppy-0.1.1-aarch64-unknown-linux-gnu.tar.gz` |
| macOS Apple silicon | `puppy-0.1.1-aarch64-apple-darwin.tar.gz` |
| macOS Intel | `puppy-0.1.1-x86_64-apple-darwin.tar.gz` |
| Windows x86_64 | `puppy-0.1.1-x86_64-pc-windows-msvc.zip` |
| Windows ARM64 | `puppy-0.1.1-aarch64-pc-windows-msvc.zip` |

Linux builds need glibc 2.35 or newer. The macOS and Windows binaries are not signed: see the README for the one-time Gatekeeper / SmartScreen step.

## Status

Early development. puppy is used and tested day to day on Linux; the full test suite passes on all six platforms, but macOS and Windows have seen little real use yet. Bug reports are very welcome.
